# logical-ai-diffusion-of-social-networks

A logical model over the diffusion of AI involvement in social networks

## Pre-requisites

Golang is required to run this program. Install from <https://go.dev/>

## Run

To run the program, simply run the command from the directory with source code:

```sh
go run .
```

## Further work / Modification

Susceptibility weights can be modified in [transform.go](./transform.go) starting line 44.
Model creation can be modified in [model.go](./models.go).
Size of randomized model and initialization can be modified in [main.go](./main.go).
